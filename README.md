# webblox
modern roblox in the browser, now for everyone. if you want a full version, it's at https://github.com/x8rr/webblox-built

# how to use this
copy the contents of `PROMPT.md` and paste it into your favorite agent! for the best results, use opus 5.5 with high thinking. feel free to use any other model.

# why doesn't this repo have any code?
this repo does not have any code because
1. implementation varies greatly across projects
2. roblox's official files are a great part of this project, so anybody using this repo can simply download them from roblox's own cdn, as opposed to the files being hosted on github and having the risk of a takedown
3. it's way easier to get an agent to implement this for you than tinkering with other roblox engine code repos
